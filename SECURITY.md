# Política de segurança

## Versões suportadas

| Versão | Suporte |
|---|---|
| 0.1.x | atualizações de segurança |
| anteriores | sem suporte |

## Como relatar uma vulnerabilidade

Não publique credenciais, dados pessoais ou detalhes exploráveis em uma issue.
Utilize **Security → Report a vulnerability** no GitHub para abrir um relato privado.

Inclua, quando possível:

- componente e versão afetados;
- passos mínimos para reprodução;
- impacto observado ou plausível;
- sugestão de correção, se houver;
- indicação de qualquer segredo ou dado que possa ter sido exposto.

O recebimento será confirmado em até sete dias. A severidade, a correção e a data de
divulgação serão coordenadas no relato privado. Não há programa de recompensa.

## Escopo

O dashboard é estático e não recebe dados ou credenciais do visitante. Relatos sobre
integridade de snapshots, dependências, workflows, publicação ou execução de código
são pertinentes. Erros metodológicos sem impacto de segurança devem usar uma issue.
